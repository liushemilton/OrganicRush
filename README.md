# Química Orgânica – O Jogo

Um jogo educativo web desenvolvido como parte de um trabalho escolar de Química. O jogador assume o papel de um monitor de Química Orgânica que precisa ajudar seus colegas a resolver dificuldades antes que o intervalo termine.

## Objetivo

Ensinar e revisar conceitos de Química Orgânica por meio de atividades interativas, desafios e situações práticas, sem utilizar questões de múltipla escolha.

## Conteúdos abordados

O jogo contempla os seguintes conteúdos:

1. Regra do octeto
2. Características do carbono
3. Hibridização do carbono
4. Hidrocarbonetos
5. Funções oxigenadas
6. Funções nitrogenadas
7. Funções sulfonadas
8. Halogênios e haletos orgânicos
9. Polímeros naturais
10. Polímeros sintéticos
11. Reatividade dos compostos orgânicos

## Tecnologias

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.

Recomenda-se utilizar a extensão Live Server do Visual Studio Code durante o desenvolvimento.
